# Security policy

## Supported versions

Only the `main` branch receives security fixes. There are no maintained release branches yet.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. If that option is not available, contact the maintainer through GitHub and ask for a private channel.

Include the affected version or commit, the steps to reproduce and the impact you expect. You will get an answer on the report thread.
